# Harshith Vankela

Welcome to my personal website—a digital archive of my journey through science, technology, and entrepreneurship.

I am a student passionate about artificial intelligence, quantum physics, entrepreneurship, psychology, and the pursuit of knowledge across disciplines. This website serves as a central hub for my projects, writings, achievements, and ongoing explorations.

## Features

- Academic and professional portfolio
- Project showcase
- Writing and Substack integration
- Achievements and milestones
- Interactive timeline
- "What I'm Exploring Now" section
- Responsive design with dark mode
- SEO and accessibility optimized

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel
